# Reglas de cálculo

- Toda operación nueva se agrega como función en `src/calculadora.py`.
- Las funciones reciben y devuelven `float`.
- `dividir(a, b)` debe lanzar `ZeroDivisionError` con el mensaje `"No se puede dividir para cero"` cuando `b == 0`.
- Los resultados se redondean a 2 decimales solo al mostrarlos, nunca dentro de la función.
